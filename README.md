## 🚀 Sobre mim

Sou estudante de Análise e Desenvolvimento de Sistemas (5º semestre) e trabalho na **CDS Sistemas**, onde comecei no suporte técnico a ERP e hoje atuo no **setor de desenvolvimento**, com PHP 8 e CodeIgniter 3.

Passei meses resolvendo problemas reais de clientes: investigando dados com SQL, configurando regras fiscais (ICMS, PIS, COFINS, IPI, NCM) e traduzindo o lado técnico para quem usa o sistema no dia a dia. Isso me deu uma visão de **negócio + tecnologia** que levo para tudo que construo.

Meu foco é me tornar **desenvolvedor back-end Java**, escrevendo código simples, organizado e fácil de manter. Gosto de entender o problema antes de sair codando.
